## The Problem Solver: Screen Door Compatibility
One of the biggest challenges for Adelaide homeowners is finding a smart lock that fits behind an **external security screen door**. Most high-end "push-pull" locks are too deep, preventing the screen door from closing.

The **DL04PRO** features a compact, slim-profile handle. This design makes it the ideal candidate for:
- **Older timber doors** with standard handle cutouts.
- **Homes with security screens** where clearance is tight.
- **Rental properties** requiring reliable, multi-user access.

## Key Access Features
The installed model provided several everyday access methods managed through the EZVIZ system:
1. **Fast Fingerprint Entry**: No more fumbling for keys in the rain.
2. **Secure CPU Cards**: Tap-and-go access for the whole family.
3. **Anti-Peep PIN Codes**: Hide your password in plain sight.
4. **Mobile Management**: View entry logs and manage users from your phone.
